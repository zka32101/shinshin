# Sound Effects

Sound effect files for the app. Each file is a short audio clip in MP3 format.

## UI Sounds
- `button_tap.mp3` - Button tap / menu selection sound
- `menu_swipe.mp3` - Menu swipe transition sound
- `page_transition.mp3` - Page transition sound

## Story Sounds
- `story_start.mp3` - Story starts playing
- `choice_made.mp3` - User selects a choice
- `story_complete.mp3` - Story completed successfully

## Achievement Sounds
- `badge_unlock.mp3` - Badge/achievement unlocked
- `points_earned.mp3` - Points earned from completing activity
- `achievement_unlock.mp3` - Major achievement unlocked

## Notification/Feedback Sounds
- `notification.mp3` - General notification
- `error.mp3` - Error occurred
- `success.mp3` - Success feedback

## Notes
- All files should be MP3 format
- Recommended bitrate: 128-192 kbps
- Recommended sample rate: 44.1 kHz
- Recommended duration: 0.3-1.0 seconds for short effects
- Keep file sizes small for mobile optimization
