**記事執筆テンプレート**

```markdown
# 小学3-4年生で判断力が育つ理由【脳科学的解説】

## はじめに
「うちの子、判断力がない...」という悩みは、親なら誰もが持っている。
でも、実は小学3-4年生は「判断力が最も育ちやすい時期」なのです。

本記事では、脳科学の観点から、なぜこの時期が重要なのか、
どう親がサポートすべきかを解説します。

## 小学3-4年の脳発達：「判断力」がついに芽生える時期

### 脳の前頭前皮質が発達し始める
- 思考・判断・感情制御を担当
- 8-10歳で急速に発達開始
- 12歳までに大人の 50% まで発達

### 具体例：子どもの変化
```
▼ 2年前（1-2年生）
「友達が悪いことしてる。どうしよう...」
→ その場で親に相談

▼ 今（3-4年生）
「友達が悪いことしてる。でも言ったら喧嘩になる...」
→ 自分で判断しようとする
```

## 判断力が育つ 3 つの条件

### ① 毎日、リアルなジレンマに直面すること
親に言われた「正解」ではなく、
自分で考える経験が重要。

例：
- 「友達がルール破ろうとしてる」
- 「自分がされたら嫌なことを、友達がやってた」
- 「先生に言うべき？黙るべき？」

### ② その判断の選択肢が複数あること
「正解は1つ」という教え方では、判断力は育たない。
「複数の選択肢の中から、自分で選ぶ」経験が大切。

### ③ その選択の結果を親が一緒に見守ること
親が「良い悪い」と評価するのではなく、
「そういう考え方もあるね」と受け入れることで、
子どもの思考が深まります。

## 親ができる 3 つのアプローチ

### 1. 日常のジレンマを「物語化」して聞く
```
❌ 悪い例：「そんなことしちゃダメ」
✅ 良い例：「そしたら、その子にはどうしたらいいと思う？」
```

### 2. 子どもの答えを否定しない
```
❌ 悪い例：「だから違う」「そんなわけない」
✅ 良い例：「そっか、そういう考えもあるね」
```

### 3. 成長を見える化する
親が「判断力が育ってるな」と感じることで、
子どもの自信につながります。

## 【実践】アプリで毎日、判断力を磨く

「小学コレ！道徳」では、この3つの条件を
すべてアプリで実現します。

- ① 毎日、リアルなジレンマを提供
- ② 選択肢型で、複数の判断を促す
- ③ 月1回のレポートで、成長を可視化

親は親向けレポートから、
効果的な声かけのアドバイスも受け取れます。

## まとめ

小学3-4年は「判断力」が最も育ちやすい時期。
その時期に、毎日のジレンマ体験と親の関わりで、
子どもの思考力・判断力は劇的に成長します。

秋リリース「小学コレ！道徳」で、
```

## 3. 記事ライティング ガイドライン

### SEO 最適化チェックリスト

```
[ ] タイトル（60字以内）に主キーワード含む
[ ] メタディスクリプション（160字）に2次キーワード含む
[ ] 見出しに キーワード と サブキーワード を自然に配置
[ ] 最初の 100 語に主キーワード 含む
[ ] 画像の alt テキストに キーワード 含む
[ ] 内部リンク 3-5個（自然な流れで）
[ ] 外部リンク 2-3個（高権威サイト）
[ ] 文字数 2,500+ 語（SEOに有利）
[ ] 段落 < 200 字（読みやすさ）
[ ] リスト形式を活用（スキャンしやすさ）
[ ] 画像・表を 2-3個 含む
[ ] 関連トピック（LSI キーワード）を自然に含む
```

### 記事テンプレート（構成）

```
1. 導入（100-200字）
   - 読者の悩みを言語化
   - なぜこれを読むべきか

2. 問題提起（300-500字）
   - 背景情報
   - 現状の課題

3. 解決策（本体，1,500-2,500字）
   - 方法論（複数提示）
   - 具体例 / ケーススタディ
   - 科学的根拠（あれば）

4. 実例紹介（500-800字）
   - ユーザーのストーリー
   - 成果数字

5. よくある質問（300-500字）
   - Q&A形式
   - 読者の疑問を先回り

6. まとめ / CTA（200-300字）
   - 記事のポイント再整理
   - アプリ / ランディングページへのリンク

合計：2,500-4,500字
```

### SEO ライティング ルール

```
【キーワード配置】
✅ タイトル：主キーワード 含む
✅ H1：主キーワード 含む
✅ H2：2-3個，2次キーワード
✅ 導入：1段落目に主キーワード
✅ 本体：自然な流れで 2-3 回

【文体】
✅ ですます調（親向けメディア）
✅ 難易度：大学 1-2 年生レベル
✅ 一文 < 60 字
✅ 段落 < 200 字

【構成要素】
✅ リスト形式：要点を3-5個
✅ 画像：3-5枚（alt text含む）
✅ 表：複雑な比較に使用
✅ 太字 / マーカー：重要な部分（過度に使わない）
```
