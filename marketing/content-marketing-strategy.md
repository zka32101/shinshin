### YouTube SEO

```
【タイトル設定】
- 主キーワード含む（最初の 30 字）
- 視聴者の関心を引く
- 例：「【脳科学解説】小学3年で判断力が急成長する理由」

【説明欄】
- 最初の 2-3 行は本文表示（重要）
- リンク 2-3 個（アプリ / ブログ / 他の動画）
- ハッシュタグ 3-5 個

【タグ】
- 日本語 10-15 個
- 英語 3-5 個

【サムネイル】
- テキスト + 顔（信頼度 UP）
- 背景：ブランドカラー（統一感）
- 文字サイズ：大きめ（スマホ対応）
```

## 8. コンテンツ分析＆最適化

### KPI 計測

```
【ブログ】
- 月間訪問者
- ページビュー数
- 平均滞在時間
- スクロール深度（50%, 90%）
- 内部リンククリック率
- コンバージョン率（LP 訪問）

【YouTube】
- 月間視聴数
- 平均再生時間
- 平均視聴時間割合（retention）
- チャンネル登録者数増加
- クリック率（サムネイル）
- 再生リスト追加数

【ポッドキャスト】
- 月間ダウンロード数
- 平均再生時間
- 購読者数
- エピソード完了率

【全体】
- オーガニック検索トラフィック
- SNS からのリファー数
- 合計オーガニックトラフィック
- コンテンツ経由コンバージョン
```

### 月次分析レポート

```
【実施内容】
毎月末、各チャネルのパフォーマンス分析

【分析項目】
1. TOP 5 記事 / 動画 / エピソード
   （理由分析：何が成功したか）

2. 低パフォーマンスコンテンツ
   （改善案：どうすればよくなるか）

3. トレンド分析
   （月次での変化・季節性）

4. ユーザーセグメント分析
   （新規 vs リピーター、デバイス別など）

5. 次月改善計画
   （テーマ・フォーマット・配信方法）
```

### A/B テスト実装

```
【テスト対象】
- ブログ：タイトル、見出し、CTA ボタン色
- YouTube：サムネイル、動画長、アップロード時間
- ポッドキャスト：エピソード長、配信日時、ゲスト有無

【実装方法】
- 2 種類を同時配信（50/50 分割）
- 2 週間計測
- 勝者版を全体展開

【計測】
Google Analytics 4 + 各プラットフォーム標準 Analytics
```
