**期間**: 2026-09-01 ~ 2027-08-31（1年）  
**対象**: 学習塾、教育機関、PTA、インフルエンサー、アプリレビューサイト  
**責任者**: パートナーシップ・チャネル開発チーム

## 1. パートナーシップ戦略

### ビジョン

```
「判断力育成」をテーマに、
教育エコシステム内での
【多層的なパートナーシップ】を構築

目的：
- 教育市場の信頼度向上
- 保護者層の多層的リーチ
- 学習塾との win-win 関係構築
- 家庭×学校×塾の 「三角形」モデル確立
```

## 2. 学習塾・教育機関との提携

### 対象塾の選定基準

```
【Tier 1: 大手塾チェーン（5-10社）】
- 生徒数：10,000+
- 対象学年：小学3-4年向けコース
- 価格：月額 800-2,000円の教材
- 例：サピックス、日能研、四谷大塚、EQWEL、くもん

【Tier 2: 地域中堅塾（20-50社）】
- 生徒数：500-5,000人
- 対象学年：小学生向け総合コース
- 価格：月額 3,000-10,000円の個別指導
- 例：地域の集団塾、個別指導塾

【Tier 3: 個別指導・家庭教師（100+）】
- 小規模だが、保護者との関係構築が容易
- 家庭教師マッチングサービス
```

```
【Tier 1: 大型インフルエンサー（フォロワー 100k+）】
- 教育系 YouTuber
- 子育てメディア運営者

- リベラルアーツ大学 両学長（金銭教育）

- 子育てハッピーアドバイス
- 脳育成の専門家

【Tier 2: 中型インフルエンサー（フォロワー 10k-100k）】
- 教育ブロガー
- 塾講師系 YouTuber
- 親向けコミュニティ運営者

【Tier 3: マイクロインフルエンサー（フォロワー 1k-10k）】
- PTA 活動者
- 学習塾講師

- ターゲット層との親和性（親 25-55 歳）
```

```
【当社の提供】
```
