# 親向けセミナー開催計画

**イベント名**: 「子どもの判断力を育てる親の関わり方」オンラインセミナー  
**開催予定**: 2026-11-15（土）10:00-11:15、15:00-16:15  
**対象**: アプリ利用者・保護者・教育関係者  
**責任者**: マーケティング・カスタマーサクセスチーム

## 1. セミナー概要

### 開催目的

```
【ビジネス目的】
- トライアル → 有料プラン 購買転換を促進
- ユーザーエンゲージメント向上（リテンション率 UP）
- ブランド認知・信頼構築
- 口コミ・SNS 拡散による新規ユーザー獲得

【社会的目的】
- 親の子育て悩みを軽減
- 判断力育成の重要性を啓発
- 家庭での効果的な教育方法を提供

【期待成果】
- 参加者 200 人（2回合計）
- トライアル利用者の 20% が有料プラン購買（40人）
- SNS シェア 100+ 回
- 満足度 85% 以上
```

### セミナー内容

```
【テーマ】 「小学3-4年で判断力を育てる親の関わり方」
【スピーカー】 教育心理学者 + 小学校教員 + CEO
【進行時間】 75分（60分講演 + 15分質問タイム）

【内容構成】
① 導入（5分）：親の悩みの可視化
② 脳科学解説（10分）：なぜ小学3-4年が重要か
③ 親の関わり方（25分）：3つのアプローチ + 実例
④ 事例紹介（10分）：アプリ利用者の成果
⑤ 「小学コレ！道徳」機能説明（10分）
⑥ 質問タイム（15分）
```

## 2. セミナー詳細テンプレート

### 講演スクリプト

```
【オープニング（5分）】

司会：こんにちは。本日はご参加ありがとうございます。

本日は「子どもの判断力を育てる親の関わり方」というテーマで、
教育心理学者の○○先生、小学校教員の△△先生と、
当社代表の□□でお話しします。

【Q】 皆さん、こんな悩みありませんか？
・「子どもが友達トラブルで相談してくるけど、正解を教えるだけでいいのか」
・「子どもの判断力が育ってるのか見えない」
・「学校の道徳の授業だけで足りるのか」

こういった親の悩みは、実は多くの家庭で共通しています。

本日は、脳科学的な背景と、具体的な親の関わり方をお伝えします。

---

【脳科学解説パート（10分）】

教育心理学者：小学3-4年生の脳には、大きな変化が起きています。

【ビジュアル】 脳の画像（前頭前皮質の発達段階）

「前頭前皮質」という、思考・判断・感情制御を担当する脳領域が、
この時期に急速に発達し始めるんです。

具体的には：
・ 6-7歳：30-40% 発達
・ 8-10歳：急速に発達開始（ゴールデンタイム）
・ 12歳：50% 達成

つまり、小学3-4年がいかに重要か、
数字で分かりますね。

【実例】
2年生の子ども：「友達が意地悪した。どうしよう」→ そのまま親に報告
3年生の子ども：「友達が意地悪した。でも言ったら喧嘩になる...」→ 自分で考えている

この「自分で考えている」プロセスが、判断力を育てるんです。

---

【親の関わり方（25分）】

小学校教員：実際の教室では、こんなシーンが見られます。

【ビジュアル】 実例イラスト（3パターン）

【実例 1】「友達がルール破ろうとしてる」
❌ 親の悪い関わり方：「そんなことしちゃダメ」「相手が悪い」
✅ 親の良い関わり方：「でも、その子にはどうしたらいいと思う？」

親が「判断の答え」を教えるのではなく、
子どもに「考えさせる」ことが大事です。

【実例 2】「自分が間違ってた。どう謝ろう」
❌ 親の悪い関わり方：「素直に謝りなさい」
✅ 親の良い関わり方：「相手は何が嫌だったと思う？」

「正直に謝る」という行動の背景にある「思考」を育てることが、
本当の判断力につながります。

【実例 3】「先生に言うべき？黙るべき？」
❌ 親の悪い関わり方：「大人に相談しなさい」
✅ 親の良い関わり方：「いろんな選択肢があるよね。君ならどうする？」

複数の選択肢を提示し、子どもが「自分で選ぶ」経験が大事です。

【3つのアプローチ】

① 毎日、子どもが「自分で判断する」ジレンマに直面させる
  親の関わり：「でも君だったらどうする？」と問いかける

② その選択肢が複数あることを示す
  親の関わり：「他にもやり方があるよ」と拡張的に考えさせる

③ その選択の結果を親が一緒に見守る
  親の関わり：「そっか、そういう考えもあるね」と受け入れる

【データ】
こういった関わり方で、3週間でどう変わるか？
（ユーザーテスト結果グラフ）
- 思いやりスコア：+20点
- 判断の速さ：+15%
- 親子コミュニケーション満足度：+30%

---

【事例紹介（10分）】

CEO：実際にアプリを使っている保護者の声をお聞きください。

【事例 1】 小学3年・女の子の母親
「月1回のレポートで、こんなに成長してるって初めて分かった。
 学校の通知表では見えない、細かい成長パターンが見える。
 親としてのモチベーションが上がった」

【事例 2】 小学4年・男の子の父親
「子どもが『今日のお話は？』と毎日聞いてくる。
 ゲーム感覚で楽しみながら判断力を磨いてる。
 親子の会話が増えた」

【事例 3】 小学3年・女の子の母親
「AI親コーチングで『効果的な声かけ』を教えてくれるのが便利。
 忙しくて子育てに迷ってた部分が、アドバイスで解決した」

---

【「小学コレ！道徳」機能説明（10分）】

CEO：では、これらの関わり方を実現するアプリをご紹介します。

【ビジュアル】 アプリのスクリーンショット

【子ども向け機能】
毎日、1つのジレンマストーリーが届きます。

例：「友達がルール破ろうとしてる。どうしたらいい？」
  → 3つの選択肢から1つ選ぶ
  → スコアが反映される

毎日の選択を通じて、スコアが変わります。
親はその変化を、月1回のレポートで確認できます。

【親向け機能①：月1回のAIレポート】
20のスコア別に、月1回レポート生成。

例：
「思いやり：85点（前月比+10点）」
「勇気：70点（+5点）」
...

さらに、AIが親向けアドバイスを自動生成：
「○○さんのお子さんは『思いやり』が高い傾向です。
 困ってる友達へのサポートを促すことで、
 さらに伸びる可能性があります」

【親向け機能②：AI親コーチング】
親の悩みに対して、Vertex AIが個別回答します。

例：「子どもが友達をいじめてないか心配」
  → AI：「こういう場合は、親が一方的に叱るより、
          子どもに『相手はどう感じてるか』を考えさせることが効果的です」

---

【質問タイム（15分）】

司会：では、ご質問をお受けします。

【予想される質問と回答】
Q1: どのくらい継続したら効果が見える？

Q2: 子どもが興味を持たず続かなかったら？

Q3: 料金体系は？
→ 月額 1,480円（税込）/ 14日間無料トライアル

Q4: 個人情報の扱いは？
→ COPPA 準拠。お名前・学年のみ。連携不可。

---

【クロージング】

本日のまとめ：
① 小学3-4年は「判断力育成のゴールデンタイム」
② 親が「答え」を教えるのではなく、「考えさせる」ことが大事
③ その習慣が、生きる力になる

「小学コレ！道徳」では、その習慣を毎日サポートします。

14日間の無料トライアルで、ぜひお試しください。

ご参加ありがとうございました。
```
