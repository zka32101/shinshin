## 1. はじめに

本利用規約（以下「規約」）は、Petitworks Inc.（以下「当社」）が提供する「小学コレ！道徳」アプリケーション（以下「本サービス」）の利用条件を定めるものです。

## 2. 定義

### 2.1 ユーザーの定義

本サービスのユーザーは以下の2層で構成されます：

#### **子どもユーザー（ユーザー）**
- 13歳未満の小学3-4年生
- 親または保護者の同意を得ている者

#### **親ユーザー（親）**
- 子どもユーザーの親または法定保護者
- 親ユーザーとしてのアカウント登録が必須

### 2.2 その他の定義

| 用語 | 定義 |
|------|------|
| **本サービス** | 小学コレ！道徳アプリ全体 |
| **コンテンツ** | 本サービスで提供されるストーリー・画像・音声等 |
| **個人情報** | メールアドレス、学年、学習履歴など |
| **知的財産権** | 著作権・商標権・特許権等の総称 |
| **サブスク** | 月額制の利用権の購入 |

## 4. アカウント登録・管理

### 4.1 登録手順

#### Step 1: 親のメールアドレス登録
```
親が有効なメールアドレスで親アカウントを作成
```

#### Step 2: 親のメールアドレス確認
```
当社から確認メールを送信
親が確認リンクをクリック
```

#### Step 3: COPPA 同意確認
```
親が同意チェックボックスにチェック
データ処理方針に同意
```

#### Step 4: 子どもプロフィール作成
```
子どもの名前（ニックネーム）
子どもの学年（1-6年）
を入力
```

### 4.2 パスワード管理

親ユーザーはパスワードを厳格に管理する義務があります：

- ✅ パスワードは定期的に変更
- ✅ 第三者とパスワードを共有しない
- ✅ 子どもにパスワードを教えない
- ✅ パスワード忘れの場合はリセットリクエスト

### 4.3 アカウント変更・削除

#### 情報変更
- 親が以下の情報を更新可能:
  - メールアドレス
  - パスワード
  - 子どものニックネーム
  - 子どもの学年

#### アカウント削除
```
親が「アカウント削除」をリクエスト
↓
30日間の猶予期間
（この間は復帰可能）
↓
30日経過後に自動削除
```

## 5. サブスクリプション・課金

### 5.1 料金プラン

```
【月額プラン】
- 月額: ¥600（税込）
- 更新日: 毎月同日
- キャンセル: いつでも可能

【年額プラン】
- 年額: ¥6,000（税込）
- 割引率: 約17% off
- 更新日: 毎年同日
- キャンセル: いつでも可能
```

### 5.2 支払い方法

支払いは以下の方法で行われます：

```
【iOS】
- Apple App Store を通じた課金
- Apple が決済情報を処理
- 当社は直接決済情報を受け取らない

【Android】
- Google Play を通じた課金
- Google が決済情報を処理
- 当社は直接決済情報を受け取らない
```

### 5.3 自動更新・キャンセル

#### 自動更新
```
サブスクは自動的に更新されます
更新日の24時間前に事前通知が送信されます
```

#### キャンセル方法
```
【iOS】
Settings → [ユーザー名] → Subscriptions
→ 小学コレ！道徳 → キャンセル

【Android】
Google Play → 自分 → 定期購入
→ 小学コレ！道徳 → キャンセル
```

### 5.4 返金ポリシー

#### 返金対象
```
- 親の要請による削除: 前月分を返金
- システム障害による利用不可: 当月分を返金
```

#### 返金対象外
```
❌ キャンセル忘れ（自動更新に気づかない）
❌ 子どもが勝手に課金した
❌ サービスの内容に満足しない
```

### 5.5 無料トライアル

```

（クレジットカードの登録が必須）
```
