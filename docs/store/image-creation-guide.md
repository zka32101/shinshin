# 画像作成ガイド

## 概要
App Store・Google Play用スクリーンショット、アイコン、プロモーション画像の作成ガイドです。
Figma、Sketch、Adobe XDなどのデザインツールを使用した実装手順を提供します。

---

## 1. 作成ツール比較

| ツール | 推奨度 | 特徴 | 価格 | 日本語対応 |
|--------|--------|------|------|-----------|
| **Figma** | ⭐⭐⭐⭐⭐ | クラウドベース、テンプレート豊富、コラボ機能 | 無料/有料 | ◯ |
| **Adobe XD** | ⭐⭐⭐⭐ | Adobe製、直感的UI | 有料 | ◯ |

**推奨**: Figma（無料版でも対応可、クラウド保存、チーム協業）

## 3. フォント設定

### 推奨フォント

#### 日本語
| 用途 | フォント | ウェイト | サイズ |
|-----|---------|--------|--------|
| **タイトル** | Noto Sans JP | Bold (700) | 60-72px |
| **サブタイトル** | Noto Sans JP | SemiBold (600) | 40-48px |
| **本文** | Noto Sans JP | Regular (400) | 32-40px |
| **細字** | Noto Sans JP | Light (300) | 24-32px |

#### 英語（多言語対応時）
| 用途 | フォント | ウェイト | サイズ |
|-----|---------|--------|--------|
| **タイトル** | Noto Sans | Bold (700) | 50-60px |
| **本文** | Noto Sans | Regular (400) | 28-36px |

### フォント入手方法

1. **Google Fonts** (無料)
   ```
   https://fonts.google.com/
   → "Noto Sans JP" をダウンロード
   ```

2. **フォントファイルインストール**
   - ダウンロード後、フォントをOSにインストール
   - Figma/Sketch は自動認識

3. **Figma での設定**
   ```
   Figma内テキスト選択
   → 右パネル「Typography」
   → フォント: Noto Sans JP を選択
   ```

## 4. Figma テンプレートの作成手順

### ステップ1: プロジェクト作成

```
1. Figma にサインイン
2. 「+ New design file」をクリック
3. ファイル名: 「小学コレ道徳_App Store」
4. ワークスペース: チーム名を選択
```

### ステップ2: フレーム設定（iPhone版）

```
1. 左パネル「Assets」で「+」をクリック
2. 「Frame」を作成
3. 右パネルで寸法設定:
   - Name: "iPhone 14 Pro Max"
   - Width: 1290px
   - Height: 2796px
4. 背景色設定:
   - Fill: Gradient（カスタム）
   - Top: #E8F4FF
   - Bottom: #E8E4FF
```

### ステップ3: グリッド設定（セーフエリア確認用）

```
フレーム選択 → 右パネル「Design」
→ 「Grid」セクション → 「+」追加
→ Grid設定:
   - Type: Grid
   - Count: 6（60px単位）
   - Gutter: 0
   - Offset: 0
```

### ステップ4: レイヤー構成

```
Frame: iPhone 14 Pro Max (1290 × 2796)
├── Background Layer (グラデーション)
├── Screenshot Layer
│   ├── Image (スクリーンショット画像)
│   └── Mask (セーフエリア内に限定)
├── Text Overlay
│   ├── Title (60px, Bold)
│   ├── Subtitle (44px, SemiBold)
│   └── Description (36px, Regular)
├── Logo Layer (右上)
└── SafeArea Guides (参考用)
```

### ステップ5: テキスト要素の追加

**テキスト追加手順**:

```
1. 「T」ツール（テキスト）をクリック
2. フレーム内で「タイトル」を配置
3. 右パネルで設定:
   - Font: Noto Sans JP
   - Weight: Bold (700)
   - Size: 66px
   - Line Height: 1.2
   - Letter Spacing: -1px（読みやすさ）
   - Color: #5B3BA3
   - Alignment: Center
```

**推奨配置**:
- タイトル: 上部 120px マージン
- サブタイトル: タイトル下 20px
- 説明文: サブタイトル下 40px

## 6. アプリアイコン作成

### サイズ仕様

| 用途 | サイズ | 形式 | 背景 |
|-----|--------|------|------|
| **App Store** | 1024 × 1024px | PNG | 不透過 |
| **Google Play** | 512 × 512px | PNG | 不透過 |
| **iOS デバイス** | 各種 | 自動スケール | Apple が角丸処理 |
| **Android デバイス** | 各種 | 自動スケール | 自動スケール |

### アイコンデザイン手順

**Figma での作成**:

```
1. フレーム作成: 1024 × 1024px
2. 背景設定:
   - Fill: Gradient
   - Top: #5B3BA3
   - Bottom: #B19CD9
3. コンテンツ配置:
   - 中央: 子どもが本を読むシンプルイラスト
   - または: 「道」の文字 + アプリ名の一部
4. パディング: 全方向 100px（セーフエリア）
5. セーフマージン確認: 内側 150px 以上
```

**デザイン指針**:
- シンプルで、小さいサイズでも識別可能
- 背景色と異なるコントラスト
- 3-4色以下に抑える
- 子ども向けらしいが、親も納得できるデザイン

**参考デザイン案**:
```
【案1】テキスト重視
┌──────────────────┐
│                  │
│     道   徳      │
│   (縦書き)       │
│                  │
└──────────────────┘
背景: 紫グラデーション

【案2】イラスト重視
┌──────────────────┐
│   [子どものイラスト]│
│  (笑顔で本を読む)   │
│      + 星マーク   │
└──────────────────┘
背景: 紫グラデーション

【案3】 アルファベット + イラスト
┌──────────────────┐
│  S   K  （SkK）  │
│  [子どもイラスト]  │
│                  │
└──────────────────┘
```


**配置の安全マージン**:
- 上下: 60px
- 左右: 80px

## 9. 書き出し設定（Figma）

### iOS / App Store 版

```
フレーム選択（iPhone版）
→ 右パネル「Design」の下部 「Export」
→「+」をクリック
→ 書き出し設定:
   - Scale: 2x（または 3x）
   - Format: PNG
   - Save As: "Screenshot_01_iPhone_1290x2796.png"
```

### Android / Google Play 版

```
フレーム選択（Android版）
→ 右パネル「Export」
→ 書き出し設定:
   - Scale: 1x
   - Format: PNG
   - Save As: "Screenshot_01_Android_1440x3120.png"
```

### アイコン書き出し

```
アイコンフレーム選択
→ 右パネル「Export」
→ 書き出し設定:
   - Scale: 1x
   - Format: PNG
   - Save As: "AppIcon_1024x1024.png"
```

## 11. 品質チェックリスト

### 解像度確認
- [ ] iPhone版: 1290 × 2796px
- [ ] iPad版: 2048 × 2732px
- [ ] Android Phone: 1440 × 3120px
- [ ] Android Tablet: 2560 × 1600px
- [ ] 拡大表示でも字が鮮明

### 色確認
- [ ] RGB色空間で作成（CMYK ではない）
- [ ] プライマリー色（#5B3BA3）が正確
- [ ] テキスト色コントラスト AAA 達成
- [ ] 暗いモードでも読める

### テキスト確認
- [ ] 日本語が正しく表示されている
- [ ] 誤字・脱字なし
- [ ] フォント：Noto Sans JP を使用
- [ ] タイトル 60-72px、本文 32-40px

### セーフエリア確認
- [ ] 重要な情報が上下 120-150px 内側
- [ ] 左右 60px 内側にテキスト配置
- [ ] ノッチ部分に重要要素がない（iOS）
- [ ] ホームインジケータに重要要素がない

### 全体確認
- [ ] 全スクリーンショット統一感がある
- [ ] 背景グラデーション・ロゴ配置が統一
- [ ] スクリーンショット枚数 5-8枚
- [ ] ファイル形式 PNG（jpg ではない）

## 12. よくある間違いと修正方法

| 間違い | 原因 | 修正方法 |
|--------|------|--------|
| テキストがぼやけ | 低解像度 | 推奨解像度で再作成 |
| 色が違う | CMYK作成 | RGB色空間で再作成 |
| テキストが切れ | セーフエリア未対応 | マージン再調整 |
| フォントが変わる | 特殊フォント使用 | Noto Sans JP に統一 |
| 日本語が文字化け | エンコーディング問題 | UTF-8で保存 |
| ノッチに隠れる | iOS セーフエリア無視 | 上部120px+余裕確保 |

## 15. バージョン管理・更新手順

### スクリーンショット更新時

**新機能追加時**:
```
1. Figma テンプレートの複製版作成
2. バージョン番号付け：v1.0, v1.1, ...
3. 新機能を反映したスクリーンショット作成
4. 旧スクリーンショット はアーカイブ保存
5. App Store / Google Play に新画像をアップロード
```

**手順**:
```
新版作成 → Figma「v1.1」プロジェクト作成
         → テンプレート複製
         → スクリーンショット更新
         → 書き出し（新フォルダに保存）
         → ストア申請時に選択
```
