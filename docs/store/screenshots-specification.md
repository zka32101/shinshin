## 3. スクリーンショット詳細仕様

### 3.1 セーフエリア（表示可能領域）

**重要なUIは画面内側に配置**
- 上部マージン: 120px
- 下部マージン: 150px
- 左右マージン: 60px

理由: デバイスのノッチ、丸角、ホームインジケータ対応

```
┌─────────────────────────────┐
│  120px マージン              │
├─────────────────────────────┤
│                             │
│  60px  【セーフエリア】  60px │
│                             │
├─────────────────────────────┤
│  150px マージン              │
└─────────────────────────────┘
```

### 3.3 色設定（背景・テキスト）

#### 背景色オプション

| パターン | 背景 | 効果 |
|---------|------|------|
| グラデーション1 | #E8F4FF → #E8E4FF | 柔らかく、お子さん向けらしさ |
| グラデーション2 | #FFF4E8 → #E8ECFF | 暖色・寒色バランス |
| 無地白 | #FFFFFF | クリーンで、コンテンツを強調 |
| 無地薄紫 | #F5F1FF | 親向け機能ハイライト |

#### テキスト色
- **タイトル/サブタイトル**: #2C3E50（深いグレー） または #5B3BA3（アプリ主色紫）
- **説明文**: #4A5568（中グレー）
- **背景が濃い場合**: #FFFFFF（白）
- **高コントラスト確保**: AAA レベル（WCAG 2.1）

### 3.4 ロゴ・ブランド配置

#### アプリロゴ配置
- **位置**: 画面上部左 または 中央上部
- **サイズ**: 高さ100-150px（スクリーンショット全体の10-12%）
- **背景**: 背景色と異なる色、または白背景の円形パネル

#### キャッチコピー
位置: タイトル下部
フォント: Noto Sans JP, 36-44px
色: #5B3BA3（アプリ主色）

推奨キャッチコピー:
- 「判断力が育つ、毎日のジレンマ」
- 「親向けレポートで成長が見える」
- 「小学生の道徳学習、ここで完結」

## 7. テキストオーバーレイ作成手順（Figma/Sketch）

### 手順1: テンプレートセットアップ
1. Figmaで新規プロジェクト作成
2. フレーム作成: 1290px × 2796px
3. グリッド設定: 60px（セーフエリア確認用）

### 手順2: レイヤー構成
```
Frame (1290 × 2796)
├── Background (グラデーション または 画像)
├── Content Layer
│   ├── Screenshot (背景画像)
│   ├── Text Overlay
│   │   ├── Title
│   │   ├── Subtitle
│   │   └── Description
│   └── Logo/Badge
└── SafeArea Guides
```

### 手順3: テキスト配置
1. タイトルを配置（セーフエリア内）
2. 説明文を配置
3. コントラストチェック（WCAG AAA）
4. セーフエリア確認
5. 書き出し（PNG, RGB, 圧縮有効）

## 8. 品質チェックリスト

### 画像品質
- [ ] 解像度が推奨値と一致
- [ ] 圧縮後もテキストが鮮明
- [ ] カラープロファイルがRGB
- [ ] 背景が切り出されていない

- [ ] フォントがシステムフォント（埋め込み無し）
- [ ] テキストが読みやすい
- [ ] コントラスト比 AAA達成
- [ ] 日本語テキストが正しく表示

### セーフエリア
- [ ] すべての重要要素がセーフエリア内
- [ ] ノッチ部分でテキストが隠れていない
- [ ] ホームインジケータ部分に余裕がある

### 各プラットフォーム別
- [ ] App Store版はiPhone/iPad両方確認
- [ ] Google Play版はアスペクト比確認
- [ ] 翻訳版テキストは適正な長さ

## 9. よくある間違いと対策

| 間違い | 原因 | 対策 |
|--------|------|------|
| テキストがノッチで隠れる | セーフエリア未対応 | マージン120px確保 |
| テキストが読みにくい | コントラスト不足 | WCAG AAA チェック |
| テキストが切れる | 解像度不足 | 推奨サイズで作成 |
| ぼやけて見える | CMYK色空間 | RGB色空間で作成 |
| フォントが変わる | 特殊フォント使用 | Noto Sans JPのみ |
| 日本語が文字化け | エンコーディング問題 | UTF-8で保存 |

## 10. 提出時の注意点

### App Store Connect
- **有効な画像形式**: PNG, JPG
- **最小サイズ**: 最大のデバイス対応（1290px以上）
- **セーフエリア**: 自動的にチェック
- **承認待機**: 24-48時間

### Google Play Console
- **有効な画像形式**: PNG, JPG
- **サイズ制限**: 最大サイズ32,768 × 32,768px
- **テキスト含有率**: 20%以下推奨（Google Playガイドライン）
- **承認待機**: 数時間～数日
