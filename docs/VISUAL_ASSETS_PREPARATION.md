## スクリーンショット仕様

### デバイス別仕様

#### App Store（iPhone）

| デバイス | 画面サイズ | 推奨解像度 | アスペクト比 |
|---------|-----------|----------|-----------|
| iPhone SE（第3世代）以上 | 4.7" | 750 x 1334 px | 16:9 |
| iPhone 8 Plus / 6s Plus | 5.5" | 1242 x 2208 px | 9:16 |
| iPhone 14 Pro Max | 6.7" | 1290 x 2796 px | 19.5:9 |
| **推奨** | 6.7" | **1290 x 2796 px** | **19.5:9** |

#### App Store（iPad）

| デバイス | 画面サイズ | 推奨解像度 | アスペクト比 |
|---------|-----------|----------|-----------|
| iPad Air | 10.9" | 2048 x 1536 px | 4:3 |
| iPad Pro | 12.9" | 2048 x 2732 px | 4:3 |
| **推奨** | 12.9" | **2048 x 2732 px** | **4:3** |

#### Google Play（Android）

| カテゴリ | 推奨解像度 | アスペクト比 |
|---------|----------|-----------|
| Phone | 1080 x 1920 px | 9:16 |
| Phone (large) | 1440 x 2560 px | 16:9 |
| Tablet | 1920 x 1200 px | 16:10 |
| **推奨** | **1080 x 1920 px** | **9:16** |

### 仕様共通要件

- **形式**: PNG（推奨）または JPEG
- **カラーモード**: RGB（P3 を推奨）
- **ファイルサイズ**: 1～2 MB 以下
- **フォント**: 日本語対応フォント
- **テキストサイズ**: 44-56 pt（読みやすさ確保）
- **セーフエリア**: 両端 50 px 余白（テキスト配置は避ける）

### ステップ 3: テキストオーバーレイ追加方法

#### 方法 1: Figma を使用（推奨）

1. **Figma で新規ファイルを作成**
   ```
   https://www.figma.com
   ```

2. **スクリーンショット画像をアップロード**
   - File > Place Image
   - スクリーンショット PNG を配置

3. **テキスト要素を追加**
   - Text Tool を選択
   - テキスト入力（日本語対応）
   - フォント: Inter（英語）/ Noto Sans JP（日本語）
   - サイズ: 56pt
   - 色: 白（RGB: 255, 255, 255）
   - シャドウ: 2-3 px（テキスト可読性向上）

4. **エクスポート**
   - PNG @ 1x（1290 x 2796 px）
   - File > Export

#### 方法 2: Sketch を使用

1. **Sketch で新規ファイルを作成**
   ```
   https://www.sketch.com
   ```

2. **スクリーンショット画像をドラッグ**
   - Insert > Image

3. **テキスト要素を追加**
   - Insert > Text
   - フォント: San Francisco / Noto Sans JP
   - 同じく 56pt、白色

4. **エクスポート**
   - File > Export > PNG

#### 方法 3: コマンドライン（ImageMagick）

```bash
# 依存関係インストール（Mac）
brew install imagemagick

# テキスト追加
convert screenshot.png \
  -font "/System/Library/Fonts/ヒラギノ角ゴシック W5.ttc" \
  -pointsize 56 \
  -fill white \
  -draw "gravity south text 0,50 '毎日のジレンマで判断力を育む'" \
  -gravity south -extent 1290x2796 \
  screenshot_with_text.png
```

## アイコン

### App Store アプリアイコン

**仕様**:
- **解像度**: 1024 x 1024 pt
- **形式**: PNG
- **背景**: 透明（PNG-8 透明推奨）
- **角丸**: 自動で適用される（データ含めない）
- **セーフエリア**: 中央 940 x 940 pt

### Google Play アプリアイコン

**仕様**:
- **解像度**: 512 x 512 px
- **形式**: PNG
- **背景**: 必須（透明は不可）
- **セーフエリア**: 中央 432 x 432 px

### アイコンデザイン要件

1. **視認性**
   - 小さいサイズ（192 x 192 px）でも識別可能
   - シンプルなデザイン
   - 子ども向けで親しみやすい配色

2. **配色**
   - 推奨: ブルー系（信頼・安心）+ アクセントカラー
   - 避ける: グレースケール、複雑な色使い

3. **モチーフ**
   - 道徳学習: 本、人物、ハート、星など
   - 親向けレポート: グラフ、レポート、成長曲線など
   - バッジ・実績: メダル、トロフィーなど

4. **デザイン方法**
   - Figma / Sketch で作成
   - または、ロゴデザイナー（有償）に依頼

### アイコン作成チェックリスト

- [ ] 1024 x 1024 pt（App Store）
- [ ] 512 x 512 px（Google Play）
- [ ] PNG 形式（App Store は透明背景）
- [ ] 複数サイズでテスト（192 x 192 px で確認）
- [ ] セーフエリア内に重要要素配置
- [ ] 色覚異常対応（カラーコントラスト確認）

## プレビュー動画

App Store のみでサポート。オプション機能ですが、推奨。

### 仕様

- **形式**: MP4（H.264 コーデック、AAC オーディオ）
- **解像度**: 1290 x 2796 px（6.7" サイズ推奨）
- **長さ**: 15～30 秒
- **フレームレート**: 30 fps
- **ビットレート**: 10～25 Mbps
- **ファイルサイズ**: 500 MB 以下

### 動画構成（推奨: 30秒）

| 時刻 | シーン | 説明 |
|------|--------|------|
| 0-3秒 | タイトル画面 | アプリロゴ＆タイトル表示 |
| 3-8秒 | ホーム画面 | ストーリー一覧スクロール |
| 8-14秒 | ストーリー体験 | ストーリー読了～選択肢体験 |
| 14-20秒 | レポート表示 | グラフ・スコア表示 |
| 20-25秒 | バッジシステム | バッジ一覧・達成感表現 |
| 25-30秒 | CTA | 「今すぐダウンロード」テキスト |

### 動画作成方法

#### 方法 1: ScreenFlow（Mac）

```bash
# ScreenFlow をインストール
# https://www.screenflow.com/

# iOS Simulator でアプリ操作
# ScreenFlow で録画
# MP4 でエクスポート
```

#### 方法 2: FFmpeg（コマンドライン）

```bash
# スクリーンショット → 動画に変換
ffmpeg -framerate 30 -i screenshot_%04d.png \
  -c:v libx264 -pix_fmt yuv420p \
  -vf "scale=1290:2796" \
  preview_video.mp4
```

#### 方法 3: 有償サービス

- キナシス（動画編集・配信サービス）
- Fiverr / Upwork（フリーランス）

## トラブルシューティング

| 問題 | 原因 | 解決方法 |
|------|------|---------|
| テキストがぼやけている | 解像度が不足 | 1.5x または 2x サイズで作成 |
| 日本語が文字化けしている | フォント対応不足 | Noto Sans JP を使用 |
| ファイルが大きすぎる | 解像度過度 | 1～2 MB の範囲に圧縮 |
| セーフエリア外にテキスト | レイアウト確認不足 | 両端 50 px 余白確保 |
| 色合いが異なる | 色空間設定異なる | RGB / P3 で統一 |
