# COPPA準拠チェックリスト

## 概要
小学コレ！道徳アプリのCOPPA（子どもオンラインプライバシー保護法）準拠状況を確認するチェックリストです。

## 実装済み項目

### 個人情報の最小化

- [x] 子どもデータで保存する情報は名前と学年のみ
  - **実装**: `firebase/firestore.rules:242-249` の `validateChildData()`
  - **検証**: 生年月日の保存を明示的に禁止

- [x] 生年月日・住所・電話番号などの PII を保存しない
  - **実装**: `lib/screens/auth/parental_consent_screen.dart:514-517`
  - **確認**: プライバシーポリシーで明記

### 親同意プロセス

- [x] 親向け同意確認画面の実装
  - 親のメールアドレス確認
  - 子どもメールアドレス確認
  - プライバシーポリシー同意
  - データ処理同意
  - 第三者共有同意
  - アナリティクス同意

- [x] COPPA準拠説明の表示
  - 米国COPPA法への準拠を明記
