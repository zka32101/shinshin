1. **アプリ起動時間**: < 3 秒
2. **ストーリー読込時間**: < 1 秒

4. **メモリ使用量**: < 100MB
5. **バッテリー消費**: 正常範囲内
6. **ネットワーク帯域**: 最適化確認
